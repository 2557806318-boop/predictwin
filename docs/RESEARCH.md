# 如何研究自己的策略

这是一份评估规范，而非已训练模型或回测报告。仓库不携带原项目样本，也不声称任何胜率或收益。

## 分开建模

- **方向概率**：预测结算方向，考虑目标价来源、距离、路径、波动、订单流和剩余时间。概率需要可靠性检验，不能用评分冒充概率。
- **反向波动风险**：估计候选至结算及执行延迟中的不利价格变化；不能仅凭一个 100ms 跳动代表整段风险。
- **执行能力**：金额覆盖、盘口价差、冲击、有效期与失败率。深度限制规模，不能直接增加方向概率。

三者的具体实现由使用者填入，框架不提供原策略阈值或训练权重。

## 防止数据泄漏

1. 用完整 `roundId` 分组，相同回合的所有样本只能属于一个训练或验证集合。
2. 按时间做 walk-forward；训练、验证之间设置覆盖标签区间的间隔，避免相邻重叠标签泄漏。
3. 只使用决策时已收到的数据；结算价、未来特征、之后更新的盘口不能回填入场特征。
4. 概率校准、阈值选择和超参数调优都只能用训练侧数据。留出集不反复调参。
5. 记录所有候选，包括拒单和 Quote 失败。只训练已成交赢家会产生选择偏差。

## 不虚构可成交利润

历史时点缺少对应实际金额 Quote 时，可以评估方向，不可声称得到了可成交费后收益。即使有 Quote，也不代表保证真实 FOK 成交；还需要回报、拒单、滑点和超时的真实证据。

| 类别 | 指标 |
| --- | --- |
| 方向与校准 | 分资产 / 方向 / 剩余时间的 Brier、LogLoss、ECE、置信区间 |
| 执行 | 实际金额匹配率、Quote RTT、有效期、变价、拒绝与未知状态比例 |
| 资金表现 | 费后净收益、对数增长、最大回撤、仓位分布、按买价分组的盈亏 |
| 数据质量 | 完整率、乱序率、延迟分位、可用 Quote 覆盖、结算标签缺失率 |

高胜率不代表赚钱：买入成本接近 1 的二元合约，单次全损可能抵消很多次小盈利。反转退出与双边对冲也必须计入新报价、双侧费用与成交风险，而不是假定能在理想价格退出。

## 上线纪律

先离线评估，再在独立纸盘观察。不得因为演示链路跑通就开放实盘。若未来要开发实盘，需额外设计订单幂等、未知状态恢复、资金预占、权限隔离和明确的人类授权；本仓库没有这些执行能力。
